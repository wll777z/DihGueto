Dúvidas

Como reservo um horário?

Escolha um serviço, uma data e um horário livre. Depois, informe seus dados e confirme. Guarde o código mostrado na tela.

Como cancelo uma reserva?

Abra “Cancelar uma reserva” na seção de agendamento. Informe a data e o código antes do horário marcado para liberar a vaga.

Posso reservar para fazer luzes?

Quando o serviço estiver disponível, selecione Luzes na agenda para ver o preço, a duração e os horários livres.
